FAQ

Oak flooring questions

Use these answers to prepare a more accurate product or installation enquiry.

Is oak flooring available as engineered and solid timber?

Oak flooring can be available in different constructions and ranges. Compare the current engineered and solid timber options, then confirm the exact product specification before ordering.

What should be checked before installing oak flooring?

Check the subfloor, moisture conditions, board direction, installation method, expansion details, transitions and site access before the installation scope is finalised.

Can an existing oak floor be colour-matched?

An exact match is not guaranteed because species appearance, finish, age and production batches vary. Samples and the existing floor should be reviewed before selecting a replacement.

How should oak flooring be maintained?

Follow the care guidance for the selected finish, remove grit, clean spills promptly and avoid unsuitable cleaners or excessive moisture. Confirm the current manufacturer instructions for the exact product.
